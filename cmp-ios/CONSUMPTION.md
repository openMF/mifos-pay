# Consuming `cmp-ios` in a fork

`cmp-ios` is the iOS app-shell — mostly generated/template-owned. A fork touches a small,
well-defined surface; everything else flows from `app-profile/` or Fastlane and should not be
hand-edited.

## What a fork touches

- **App identity** — never hand-edit `Configuration/Config.xcconfig`. Set
  `app-profile/app.yaml#identity.app_id` / `identity.app_name` and run `./gradlew syncForkConfig`;
  it regenerates `APP_BUNDLE_ID` / `APP_NAME` (and `TEAM_ID` from your Apple Developer team).
- **Icons** — drop a source icon into `app-profile/icons/` (see that directory's README for the
  exact filename); `syncForkConfig` copies it to
  `iosApp/Assets.xcassets/AppIcon.appiconset/AppIcon.png`.
- **Signing** — Fastlane Match (adhoc for Firebase distribution, appstore for TestFlight/App
  Store) — configured via `scripts/ios/setup_ios_complete.sh`, not by editing project files. See
  [`docs/ios/IOS_SETUP.md`](../docs/architecture/tree/deployment/ios/setup.md).
- **App UI code** — `ContentView.swift` / `iOSApp.swift` are a thin host; the actual UI is
  `ComposeApp` (Kotlin, from `cmp-shared` + `cmp-navigation`). You almost never edit Swift here —
  extend the Compose side instead.

## What to leave to sync / generation

- `Configs/*.xcconfig` — regenerated by `./gradlew generateIosFlavorXcconfigs`
  (`com.mobilebytelabs.kmp-product-flavors`); headed "DO NOT EDIT".
- `scripts/embed-xcframework.sh` and the `Package.swift` binary-target path — template
  infrastructure for embedding the KMP-built `ComposeApp.xcframework`; a template fix flows
  upstream, never a local patch (per the template-fix-upstream discipline for template-derived
  files).
- `iosApp.xcodeproj/project.pbxproj` build-phase wiring for the `[KMP] Embed and Sign` script.

## Building locally

Xcode's Run-Script phase does the framework build for you on every build/archive — you don't run
the `assembleComposeApp*XCFramework` Gradle tasks by hand except when resolving the SwiftPM
`Package.swift` path directly (`./gradlew :cmp-shared:assembleComposeAppReleaseXCFramework`).

See [`docs/ios/IOS_DEPLOYMENT.md`](../docs/architecture/tree/deployment/ios/deployment.md) and
[`docs/ios/IOS_DEPLOYMENT_CHECKLIST.md`](../docs/architecture/tree/deployment/ios/checklist.md) for release lanes.
